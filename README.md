# Ліцей — 3D фасад

Інтерактивна 3D-модель фасаду Криворізького природничо-наукового ліцею.
Статичний сайт без збірки: відкривається як звичайна сторінка, рендериться
у браузері через [three.js](https://threejs.org/), модель можна експортувати
в OBJ + MTL або GLB.

## Запуск локально

Сторінці потрібен HTTP — емблема вантажиться через `fetch`, а він на `file://`
блокується політикою походження. Достатньо будь-якого статичного сервера:

```bash
python3 -m http.server 4173
```

Далі відкрити <http://localhost:4173>.

## Публікація на GitHub Pages

Залити вміст цієї теки в корінь репозиторію, після чого:
**Settings → Pages → Deploy from a branch → `main` → `/ (root)`**.

Точка входу — `index.html`. Файл `.nojekyll` вимикає обробку Jekyll: без нього
Pages може відкидати частину файлів і зайво вповільнює деплой.

## Керування

| Дія | Миша | Тачскрін |
| --- | --- | --- |
| Обертання | перетягування | один палець |
| Масштаб | коліщатко | щипок |
| Панорамування | перетягування правою | два пальці |

Кнопки внизу праворуч зберігають модель у **OBJ + MTL** або **GLB**. GLB імпортує
будь-який сучасний 3D-редактор; FBX з браузера експортувати неможливо.

## Структура

| Шлях | Призначення |
| --- | --- |
| `index.html` | Точка входу Pages. Уся геометрія фасаду будується тут, у метрах, y-up. |
| `three-d-stage.js` | Веб-компонент `<three-d-stage>`: рендерер, освітлення, орбітальні контроли, експорт. Копія стартера — правити лише свідомо, ре-імпорт зі стартера перезапише файл. |
| `uploads/2026-08-30-21-44-36.jpg` | Єдиний рантайм-ассет: світлина емблеми, з якої знімається текстура. |
| `lyceumFacade.dc.html`, `lyceumFacadeV2.dc.html` | Креслення фасаду (артборди Claude Design). До 3D-сторінки не підключені. |

## Як влаштована модель

Геометрія зібрана з примітивів у реальних метрах. Ключові осі й позначки винесені
в константи на початку модуля:

```js
const L = 66.1;                 // повна довжина фасаду, осі 1–4
const AX3 = 39.0;               // вісь 3 — межа між класами й залами
const GND = -1.58, PL = -0.38, TOP = 7.42;
```

Хелпер `box(name, mat, x, y, z, w, h, d)` задає паралелепіпед від мінімального
кута, а не від центра, — так розміри читаються прямо з креслення. Кожен меш і
матеріал має ім'я: саме ці імена стають записами `o` та `usemtl` в експортованому
OBJ, тому їх варто лишати осмисленими.

Фасадна «шкіра» (`facadeSkin`) будується як суцільна стіна з вирізаними отворами:
список прорізів сортується, і стіна нарізається смугами між ними. Додаючи вікно,
його треба внести і в масив прорізів — інакше воно опиниться всередині глухої стіни.

Оточення (небо, газон, паркан, дорога) винесене в окрему групу `environment`.
Вона додається повз `stage.setObject()`, тому не потрапляє ні в кадрування камери,
ні в експорт — вивантажується лише сама будівля.

## Залежності

three.js `0.184.0` вантажиться з unpkg через `<script type="importmap">` із
закріпленими SRI-хешами. Версію й хеші треба міняти разом — інакше браузер
відхилить модуль. Збірки й `node_modules` проєкт не потребує.

## Відомі обмеження

- Глибина корпусів (`D1`, `D2`) прийнята орієнтовно — поверхових планів не було.
- Без мережі сторінка не працює: three.js тягнеться з CDN. Якщо потрібна
  автономність, скачайте бібліотеку в репозиторій і перепишіть `importmap` на
  локальні шляхи.
- `uploads/` важить близько 6 МБ, з яких сторінка використовує один файл. Решта —
  вихідні матеріали проєкту; вони лишаються в репозиторії свідомо (див. нижче).
  На швидкість сторінки це не впливає: браузер вантажить лише те, на що є посилання.

## Зв'язок із Claude Design

Репозиторій — дзеркало проєкту в Claude Design; `index.html` тут відповідає
`Lyceum 3D.html` там. Тому вихідні матеріали (`uploads/`, `scraps/`, `.dc.html`,
`support.js`) не видаляються, навіть якщо сторінка їх не використовує.

Правки під Pages залиті назад у Design, тож `index.html` і `Lyceum 3D.html`
збігаються за вмістом. Повторний імпорт більше не відкочує фікс шляху до емблеми.

Що саме було вирівняно:

| Правка | Навіщо |
| --- | --- |
| `EMBLEM_SRC` вказує на `2026-08-30-21-44-36.jpg` | Раніше в Design світлина звалась `2026-08-30 21.44.36.jpg`, а експорт перейменовував файли під дефіси, не чіпаючи посилання. Сторінка падала з 404 і не рендерилась взагалі. Тепер копія під дефісним іменем лежить в обох місцях. |
| Завантаження емблеми через `fetch` → `blob` | Canvas лишається same-origin. |
| Емблема в `try/catch` | Декоративна текстура не має ронити всю модель. |
| `<meta viewport>`, `100dvh`, favicon | Потрібні для Pages; у канві нешкідливі. |
| Заставка `#boot` і глобальний обробник помилок | Модель будується в top-level `await`: без цього будь-який збій давав порожній екран без пояснень. |

Повного побайтового дзеркала немає й не буде — це нормально:

- `.nojekyll`, `README.md`, `.gitignore` потрібні лише репозиторію;
- решта файлів у `uploads/` зветься в Design із пробілами, а експорт замінює їх
  на дефіси — на роботу сторінки це не впливає, бо посилається вона тільки на емблему;
- артборди в Design звуться `Фасад ліцею.dc.html`, у репозиторії — `lyceumFacade.dc.html`.

У Design лишилась і стара копія світлини під іменем із пробілами — як запасний
варіант. Якщо вона не потрібна, її можна видалити прямо в редакторі.
